```

budget 1500€. C'est faisable ?"
```

**Je fais** :
```
1. SKILL_METIER 16Q → "Attends, c'est vinyl adhésif FIXE ou tu dis monomère ?"
2. SKILL_METIER 6C → "Si 18 mois extérieur, vinyl polymère obligatoire (pas monomère)"
3. SKILL_METIER 7E → "Timeline : découverte 1j, audit 1j, recommandation 1j..."
4. SKILL_MANAGEMENT → "3 partenaires pour sourcing, planning 2 semaines OK"
5. SKILL_QUALITE → "Budget justifié : vinyl polymère 0.6€/m², lamination mat 0.3€/m²..."
```

**Je réponds** :
```
✓ OUI c'est faisable

Recommandation : Vinyl polymère (pas monomère!)

Budget : 1500€ OK (un peu serré mais possible)
Sourcing : 2 partenaires capables 3-4 semaines
Timeline : Jour 7 estimation, Jour 17 production, Jour 21 livraison

Risque 1 : Date fixe tight → pas de modif post-BAT possible
Risque 2 : Couleur exacte demandée → épreuve obligatoire (+100€, +3j)

Prochaines étapes :
1. Confirmez vinyl polymère avec client
2. Demandez fichier design
3. Lancez sourcing 2 partenaires
4. Planifiez audit site pour préparation surface

## 🎓 COMMENT ÊTRE PLUS PRODUCTIF AVEC MOI

### ✅ BONNES PRATIQUES

**1. Soyez spécifique**
- ❌ "J'ai une question" → trop vague
- ✅ "Panneau façade béton 5 ans, budget 3k" → concis

**2. Contexte clair**
- ❌ "C'est quoi la matière ?" → trop flou
- ✅ "Façade brut plein sud, 5 ans — quelle matière ?" → contexte

**3. Objectif final**
- ❌ "Raconte-moi" → générique
- ✅ "J'ai besoin d'une recommandation pour client" → but clair

**4. Référez-vous aux Skills**
- Vous : "Regarde SKILL_METIER Section 4 question 8..."
- Moi : (Je trouve + je cite + je réexplique)

---

### ❌ À ÉVITER

- ❌ "C'est normal que...?" sans contexte → trop vague
- ❌ "Pourquoi ?" sans expliquer le problème
- ❌ "Fais ça pour moi" (je vous aide, pas j'exécute)
- ❌ Donner infos sensibles (prix, marges, noms clients)
