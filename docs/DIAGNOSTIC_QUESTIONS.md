# Questions Diagnostiques PrimeCenter - Le Questionnaire "20 ans de Métier"

**Objectif** : Révéler le besoin réel en 5-10 min d'appel, anticiper 80% des risques.

**Mode d'emploi** : Poser les questions dans cet ordre (progressif). Adapter la profondeur selon le projet.

---

## 🎯 PHASE 1 : DÉCOUVERTE RAPIDE (2-3 min)

### Q1. **Quelle est exactement la destination finale du support ?**
**Réponses types** : Vitrine commerce | Façade bâtiment | Véhicule | Intérieur bureau | Décor événement | Chantier | Terrain agricole | etc.

**Pourquoi c'est crucial** :
- Intérieur vs extérieur = expositions UV/pluie totalement différentes
- Vitrine = couleur critique (approche) vs chantier = coût priorisé
- Révèle aussi la durée de vie et l'esthétique attendue

**Suivi** : Si "façade bâtiment extérieur" → continuer Q2. Si "vitrine commerce" → adapter questions (moins rigidité nécessaire par ex).

---

### Q2. **Combien de temps faut-il que ça tienne ?**
**Réponses types** : 2 jours (événement) | 1 mois (promo) | 3-6 mois (saison) | 1-2 ans (standard) | 3-5 ans (pérenne) | 5-7 ans (longue durée) | Permanent

**Pourquoi c'est crucial** :
- **Durée = coût** : 3 mois en monomère ≠ 3 ans en polymère + lamination
- **UV résistance** : Faible durée = encres standard OK | Longue durée = UV resistant obligatoire
- **Cycles de test/validation** : Plus c'est long, plus il faut buffer délai + épreuves

**Suivi** : Si "1-2 ans" ET "extérieur" → probablement vinyl polymère + lamination. Si "3 jours" → monomère OK.

---

### Q3. **C'est temporaire (démontable) ou définitif ?**
**Réponses types** : Temporaire/démontable | Semi-permanent (peut retirer) | Définitif/pérenne

**Pourquoi c'est crucial** :
- **Adhésif** : Temporaire = repositionnable | Permanent = adhésif 100% non-résiduel requis
- **Arrachement risque** : Temporaire = moins de risque dégât surface | Permanent = audit support CRITIQUE
- **Coût retrait** : Influence planning + coût main d'œuvre

**Suivi** : Si "temporaire" + "3 jours" → vinyl monomère léger adhésif standard. Si "définitif" + "5 ans" → primaire + audit support préalable.

---

## 🎯 PHASE 2 : AUDIT SUPPORT (3-5 min)

### Q4. **Sur quoi exactement on va coller ou poser ce support ?**
**Réponses types** :
- Verre (lisse) | Verre dépoli
- Peinture (intérieur mate / laquée brillante)
- Béton brut | Béton peint
- Acier/métal | Galvanisé
- PVC rigide | Polycarbonate
- Bois (brut / peint / verni)
- Carrelage | Marbr
- Acier inox
- Tôle ondulée
- Autre

**Pourquoi c'est crucial** :
- **Énergie de surface** : Verre lisse (haut) ≠ béton brut (bas) = adhésif différent
- **Arrachement risque** : Peinture branlante = catastrophe en permanent
- **Préparation** : Béton poreux = nettoyage + primaire possibles
- **Rayon courbe** : Besoin film conformable vs rigide possible

**Suivi** : Si "peinture" → Q5. Si "béton brut" → Q5 + audit préparation. Si "verre" → simpler, moins de risque adhésion.

---

### Q5. **État du support : lisse, texturée, poreuse ? Sale, poussière, humidité ?**
**Réponses types** :
- Parfaitement lisse et propre
- Légère texture (peinture standard)
- Très texturée (crépi, béton brut)
- Poreuse (bois nu, béton)
- Sale / poussière visible
- Humidité (peut sentirc)
- Moisissures / algues (vert)
- Eau stationnaire

**Pourquoi c'est crucial** :
- **Adhésion risque** : Poussière = perte adhésion 40% | Humidité = bulle + décollement inévitable
- **Préparation** : Nécessite nettoyage + temps séchage
- **Conformabilité** : Texturée = besoin film conformable (polymère/coulé) vs monomère trop rigide
- **Pérennité** : Moisissures = adhesif non-viable, retrait garanti

**Suivi** : Si "parfait état" → continuer simplement. Si "sale + humide" → AUDIT SITE OBLIGATOIRE + plan de préparation.

---

### Q6. **Qui va poser ? Et combien de temps avez-vous pour la pose ?**
**Réponses types** :
- Notre équipe interne (niveau expérience ?)
- Client lui-même
- Poseur spécialisé que nous engageons
- Poseur client (sous sa responsabilité)
- Combiné (nous + client)

**Pourquoi c'est crucial** :
- **Niveau exigence** : Poseur pro = tolérances strictes OK | Client amateur = géometries simples
- **Responsabilité** : Qui assume risque de mal posée ? Assurance ?
- **Délai critique** : Pose fixe = date immobile (pénalité potentielle)
- **Complexité** : Détourage fin = poseur expérimenté OBLIGATOIRE

**Suivi** : Si "poseur spécialisé" → peut complexifier. Si "client amateur" → simpler designs, support pré-appliqué possible.

---

### Q7. **Y a-t-il des contraintes difficiles de pose ou site ? (Accès, nacelle, sécurité, température…)**
**Réponses types** :
- Accès normal (échelle simple, sol stable)
- Accès difficile (nacelle, travail hauteur, zone sensible)
- Température extrême (hivernale, tropicale)
- Zone sensible (hôpital, école, zone publique)
- Délai serré (installation urgente)
- Conditions humides (pluie possible)
- Vibrations (structure mobile, véhicule)

**Pourquoi c'est crucial** :
- **Nacelle** = surcoût + timing critique + assurance requise
- **Température bas** = temps séchage adhésif doublé | Température haut = risque bulle
- **Zone sensible** = peut nécessiter certifications (M1 inflammabilité, hygiène)
- **Conditions pluie** = reporte pose, buffer délai obligatoire

**Suivi** : Si "nacelle + hauteur" → surcoût pose + planning serré. Si "climat tropical" → vinyl coulé résistance thermique.

---

## 🎯 PHASE 3 : ENVIRONNEMENT PHYSIQUE (2-3 min)

### Q8. **Exposition éléments : UV (plein sud ?), pluie, vent, pollution…?**
**Réponses types** :
- Intérieur pur (pas d'UV direct)
- Semi-couvert (UV indirect, pluie rare)
- Exposition plein sud (UV max, plein jour)
- Bord mer (salt spray, pollution)
- Zone industrielle (pollution, vapeurs)
- Route intense (pollution gaz, poussière)

**Pourquoi c'est crucial** :
- **UV dégradation** : Plein sud = durée réelle -40% vs ombre
- **Stabilité couleur** : Photos perte teinte visible en 12-18 mois plein UV si pas lamination
- **Lamination** : Ombre = brillant OK | Plein sud = mat anti-UV OBLIGATOIRE
- **Matière** : Extérieur UV = polymère coulé + encre résistante

**Suivi** : Si "plein sud 3-5 ans" → vinyl coulé + lamination mat anti-UV. Si "intérieur pur" → vinyl monomère OK.

---

### Q9. **Risques physiques : vandalisme, graffiti, nettoyage agressif, trafic, abrasion ?**
**Réponses types** :
- Aucun risque (zone protégée)
- Trafic modéré (piétons occasionnels)
- Trafic intense (zone commerciale)
- Nettoyage fréquent (vitrine, équipement)
- Risque graffiti (zone à risque)
- Risque vandalisme (zone difficile)
- Rayures contact (rails, équipement)

**Pourquoi c'est crucial** :
- **Lamination anti-graffiti** : Zone à risque = nécessaire (coût +15-20%)
- **Résistance abrasion** : Nettoyage fréquent = polymère coulé résistant + finition adapté
- **Coût retouche** : Si vandalisme fréquent → budget révision/remplacement
- **Type nettoyage** : Eau chaude OK vs solvants → marque risques

**Suivi** : Si "zone à graffiti" → lamination anti-graffiti incluse. Si "nettoyage quotidien" → finition satin/mat robuste.

---

### Q10. **Réglementation ou certification requise ? (ERP public, M1 inflammabilité, accessibilité, hygiène…?)**
**Réponses types** :
- Aucune (usage privé/externe simple)
- M1 inflammabilité (décor intérieur public, école, hôpital)
- Accessibilité PMR (signalétique normalisée)
- Hygiène alimentaire (cuisine, boucherie)
- Normes chimiques (zone ATEX, chimie)
- Autre

**Pourquoi c'est crucial** :
- **Certifications** : M1 requis = matière + tests obligatoires (délai +15 jours, coût +20%)
- **Traçabilité** : Déclaration de conformité, certification fournisseur
- **Responsabilité** : Produit non-certifié en zone réglementée = responsabilité civile

**Suivi** : Si "école intérieur" → M1 obligatoire, vérifier vinyl/bâche certifiée.

---

## 🎯 PHASE 4 : ATTENDU VISUEL & MARQUE (2-3 min)

### Q11. **Y a-t-il des couleurs critiques ou match exact de marque demandé ?**
**Réponses types** :
- Couleur libre, pas d'exigence précise
- Couleurs proches charte, tolérance standard
- Couleur critique : logo bleu = exact Pantone
- Match parfait : compérison directe charte couleur peinture/tissu

**Pourquoi c'est crucial** :
- **Coût épreuve** : Couleur critique = épreuve contractuelle incluse (+2-3 jours, +50-100€)
- **Tolérance** : "Proche" = ΔE < 3-5 OK | "Exact" = ΔE < 2 obligatoire
- **Responsabilité** : Sans épreuve → client assume variations écran/impression naturelles
- **Gestion couleur** : Profil ICC + calibration machine obligatoires

**Suivi** : Si "couleur critique" → épreuve incluse automatique, budget +3 jours. Si "libre" → simplifier BAT.

---

### Q12. **À quelle distance les gens vont regarder ce support ? (Proximité, moyen distance, loin…?)**
**Réponses types** :
- Proximité (< 1m) : détail important
- Proximité-moyen (1-3m) : lecture principal
- Moyen distance (3-10m) : visibilité générale
- Loin (> 10m) : silhouette + couleur seulement
- Mixte (proche + loin)

**Pourquoi c'est crucial** :
- **Résolution utile** :
  - Proximité = 300 ppi obligatoire
  - Moyen = 240 ppi OK
  - Loin = 150-200 ppi suffisant
- **Détail** : Proximité = polices fines lisibles OK | Loin = polices ≥ 18pt
- **Techno** : Proximité = UV plat qualité max | Loin = éco-solv budget OK

**Suivi** : Si "proximité (vitrine)" → 300 ppi, police ≥ 12pt, UV recommandé.

---

### Q13. **Quel niveau de finition attendu ? Premium, standard, ou économique ?**
**Réponses types** :
- Économique (budget minimisé, esthétique basique)
- Standard (bon compromis qualité/coût)
- Premium (finition impeccable, détails soignés)

**Pourquoi c'est crucial** :
- **Techno** : Écono = éco-solv, vinyl monomère | Premium = UV plat, vinyl coulé
- **Matière** : Écono = PVC 1mm | Premium = Dibond 6mm
- **Finition** : Écono = prise direct | Premium = contrecollage alu + cadrage
- **Budget** : Premium = 2-3x écono potentiellement

**Suivi** : Aide orienter choix techno/matière basé sur budget client confirmé.

---

## 🎯 PHASE 5 : LOGISTIQUE & PLANNING (2 min)

### Q14. **Date fixe d'installation ? Pénalités prévues si on dépasse ?**
**Réponses types** :
- Pas de date fixe (flexible)
- Date cible (buffer 3-5 jours OK)
- Date contractuelle (pénalité par jour)
- Installation événement (date immobile)

**Pourquoi c'est crucial** :
- **Buffer délai** : Date contractuelle = ajouter 30-50% délai production + transport
- **Urgence** : Si tight, refuser complexité (détourage fin, couleur critique)
- **Pénalité** : Si mentionnée = surcoût assurance retard potentiel

**Suivi** : Si "date contractuelle" → confirmer délai réaliste, remonter risques early.

---

### Q15. **Volume : c'est une série unique, des variations (noms magasins, langues), ou réassorts prévus ?**
**Réponses types** :
- Pièce unique
- Série courte (< 5 variations)
- Série moyenne (5-20 variations)
- Réassorts annuels (même design, refonte possible)

**Pourquoi c'est crucial** :
- **Archivage fichiers** : Réassorts → conserver sources +5 ans min
- **Economies d'échelle** : Série = meilleur tarif / quantité (massification)
- **Modularité** : Variations = template + variables (noms, couleurs…) = automatable
- **Gestion stock** : Réassorts = partenaire dedié, SLA clair

**Suivi** : Si "réassorts annuels" → contrat partenaire longue durée. Si "pièce unique" → flexible.

---

### Q16. **Emballage / livraison : quel format, quels sites, quels horaires ?**
**Réponses types** :
- Pickup atelier (client vient chercher)
- Livraison point unique (adresse simple)
- Multi-sites (plusieurs points livraison)
- Conditions spéciales (pas d'escalier, monte-charge, accès contraint)

**Pourquoi c'est crucial** :
- **Découpe format** : Multisites = devoir découper en portions transportables
- **Emballage** : Fragile (Dibond, verre) = protection renforcée (+coût)
- **Délai** : Livraison multi-sites = coordinatino logistique compliquée
- **Assurance** : Produits précieux = besoin assurance transport

**Suivi** : Si "multisites + découpe" → prévoir surcoût logistique + délai.
