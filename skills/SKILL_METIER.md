## 📚 SECTIONS

### 1️⃣ LES 7 BLOCS TECHNIQUES

#### BLOC 1 : Technologie Print
| Techno | Quand ? | Avantages | Limites |
|--------|--------|----------|---------|
| **UV Plat** | Rigides premium, qualité max | Haute qualité, fonds noirs riches, ppi élevé | Odeur UV, pas de rolls, énergie |
| **UV Roll** | Campagnes vinyl, films | Productivité, haute qualité | Moins de variété supports |
| **Éco-solvant** | Vinyl standard, budget maîtrisé | Moins toxique, adhésion directe | Qualité légèrement moins brillante |
| **Résine/Latex** | Contexte public, low-VOC | Séchage rapide, odeur | Contrastes moins marqués |
| **Sublimation** | Textile polyester | Rendu unique, intégration fibre | Support limité (polyester) |

#### BLOC 2 : Prépresse & PDF
**Règle d'Or** : Un PDF mauvais = impression mauvaise, même sur bonne machine.

**À vérifier obligatoirement** :
- ✓ Dimensions = production + 5mm fonds perdus minimum
- ✓ Résolution ≥ 240 ppi (idéal 300)
- ✓ Noirs : K100 pur OU riche (C30M30Y30K100) — décider
- ✓ Transparences : localiser, limiter
- ✓ Traits fins ≥ 0.5pt (< risque disparition)
- ✓ Surimpressions : documentées (overprint black ?)
- ✓ Polices : courber obligatoirement
- ✓ Images CMYK pur (pas spot + CMYK)

#### BLOC 3 : Finition & Fabrication
**Lamination** :
- Brillant = contraste max, premium, sensible rayures → vitrine/qualité
- Mat = discrétion, pas reflets → intérieur/moderne
- Satin = hybride, toucher doux
- Anti-graffiti = zone à risque obligatoire

**Découpe & Usinage** :
- Mi-chair = vinyl sur support, garder support intact
- Détourage = découpe complexe, forme exacte
- Rainage = plis guides sans craquage
- Contrecollage = coller 2+ matières
- Œillets/Fourreaux = renforcement + fixation

#### BLOC 4 : Diagnostic Client (16 Questions Essentielles)

**PHASE 1 : DÉCOUVERTE (2-3 min)**
1. Destination exacte ? (intérieur/extérieur/vitrine/véhicule/chantier)
2. Durée de vie requise ? (2j/1m/3m/1an/3ans/7ans/permanent)
3. Temporaire ou définitif ?

**PHASE 2 : AUDIT SUPPORT (3-5 min)**
4. Sur quoi coller exactement ? (verre/peinture/béton/métal/bois)
5. État du support ? (lisse/texturé/poreux/sale/humide)
6. Qui pose ? (équipe interne/client/spécialisé)
7. Contraintes pose ? (nacelle/température/sécurité/délai)

**PHASE 3 : ENVIRONNEMENT (2-3 min)**
8. Exposition UV/pluie/vent ? (plein sud/semi/abrité)
9. Risques physiques ? (vandalisme/graffiti/abrasion/nettoyage)
10. Réglementation ? (M1/ERP/accessibilité/hygiène)

**PHASE 4 : ATTENDU VISUEL (2-3 min)**
11. Couleurs critiques ? (libre/proche/exact Pantone)
12. Distance de lecture ? (proximité/moyen/loin)
13. Finition attendue ? (économique/standard/premium)

**PHASE 5 : LOGISTIQUE (2 min)**
14. Date fixe ? (flexible/cible/contractuelle/immobile)
15. Volume ? (unique/variations/réassorts)
16. Emballage/livraison ? (pickup/point unique/multi-sites)

### 2️⃣ LES 6 CRITÈRES DÉCISIONNELS (Arbre Matière)

**Ordre d'application** : DURÉE → USAGE → SUPPORT → GÉO → BUDGET → ESTHÉTIQUE

#### CRITÈRE 1 : DURÉE (élimine solutions)
```
< 7 jours       → Carton OU Vinyl monomère
1-3 mois        → Vinyl monomère + lamination simple
3-12 mois       → Vinyl polymère + lamination adapté
1-3 ans         → Vinyl polymère/coulé + lamination mat
3-7+ ans        → Vinyl coulé + lamination anti-UV (OBLIGATOIRE)
```

#### CRITÈRE 2 : USAGE (détermine famille)
```
Intérieur pur           → Vinyl adhésif ✓ (simple, budget)
Extérieur semi-abrité   → Vinyl polymère + lamination
Extérieur plein UV      → Vinyl coulé + lamination anti-UV
Vitrine/verre           → Film transparent OU vinyl monomère
Véhicule                → Vinyl coulé polymère (thermostabilité)
Textile/mur tendu       → Polyester enduit (SEG) ✓
```

#### CRITÈRE 3 : SUPPORT (détermine adhésif)
```
Verre lisse             → Vinyl adhésif ✓ (adhésion facile, énergie haute)
Peinture lisse          → Vinyl adhésif ✓ (audit surface = CLÉS)
Peinture texturée       → Vinyl polymère/coulé ✓ (conformabilité)
Béton brut              → Primaire + Vinyl polymère ✓ (porosité)
Plastique (PVC/PC)      → Adhésif spécifique ✓ (énergie basse)
Métal (inox/galva)      → Vinyl adhésif ✓ (facile)
Bois                    → Préparation + vinyl ✓ (si peint)
```

#### CRITÈRE 4 : COMPLEXITÉ GÉOMÉTRIQUE (rigidité vs conformabilité)
```
Simple + plane          → Vinyl monomère ✓, PVC, Dibond OK
Complexe + modérés      → Vinyl polymère/coulé ✓ (conformable)
Reliefs importants      → Vinyl coulé ✓✓ (seul choix fiable)
Détourage fin           → Poseur expérimenté OBLIGATOIRE
Assemblage pièces       → Contrecollage + bridage alu
```

#### CRITÈRE 5 : BUDGET (affine techno impression)
```
ÉCONO               → Carton / Vinyl monomère / PVC 1mm / Éco-solv
STANDARD            → Vinyl polymère / Alvéolaire / PVC 3mm / Éco-solv
PREMIUM             → Vinyl coulé / Dibond / Textile / UV plat
```

#### CRITÈRE 6 : ESTHÉTIQUE (finition finale)
```
Brillant            → Vinyl standard + brillant naturel OU Dibond laqué
Mat discret         → Vinyl + lamination mat ✓
Satin/soyeux        → Vinyl polymère + lamination satin ✓
Texture grainée     → Vernis spécialisé (Dibond)
Textile naturel     → Mur tendu / drapeaux ✓✓
Antireflet          → Lamination antireflet (premium)
```

### 3️⃣ MÉTHODOLOGIE EN 7 ÉTAPES (Workflow Complet)

#### 🔵 ÉTAPE 1 : DÉCOUVERTE USAGE
**Input** : Client brief brut
**Actions** :
- Poser Q1-3 (destination, durée, temporaire)
- Évaluer urgence et complexité
**Output** : Fiche usage + durée de vie

#### 🟢 ÉTAPE 2 : AUDIT SUPPORT
**Input** : Fiche usage
**Actions** :
- Poser Q4-7 (support, état, pose, contraintes)
- Recommander audit site si besoin
**Output** : Checklist support + contraintes physiques

#### 🟡 ÉTAPE 3 : RECOMMANDATION TECHNIQUE
**Input** : Fiche usage + audit support
**Actions** :
- Appliquer 6 critères décisionnels
- Évaluer alternatives (économique/standard/premium)
- Identifier risques early
**Output** : Matière + techno + finition + budget estimé

#### 🔴 ÉTAPE 4 : SPÉCIFICATIONS FICHIERS
**Input** : Recommandation technique
**Actions** :
- Définir dimensions fichier (production + 5mm)
- Format PDF/X-4 obligatoire
- Définir noirs, surimpressions, résolution
- Créer gabarit pour client
**Output** : Specs PDF/X + Gabarit + Préflight rules

#### 🟣 ÉTAPE 5 : ÉPREUVE / BAT
**Input** : Fichier client validé
**Actions** :
- Générer PDF visuel + specs écrites
- Évaluer si épreuve physique nécessaire (couleur critique ?)
- Document BAT contractuel
**Output** : PDF BAT signé + conditions couleur

#### 🟠 ÉTAPE 6 : PRODUCTION + QC
**Input** : BAT signé + job ticket
**Actions** :
- Vérifier machine calibrée (profil ICC)
- Test premier tirage OK
- Tous les tirages contrôlés (couleur, traits, ΔE)
- Finition conforme + photos qualité
**Output** : Produit conforme + PV qualité

#### 🔵 ÉTAPE 7 : LIVRAISON / POSE
**Input** : Produit fini
**Actions** :
- Photo avant/après pose
- PV réception (conformité)
- Conditions SAV documentées
- Archivage projet 5 ans minimum
**Output** : PV + Archivage + Lessons learned

### 4️⃣ FAMILLES DE MATIÈRES (Quick Reference)

#### VINYLES ADHÉSIFS
**Monomère** : 2-3 ans, adhésif standard, budget de base
→ Quand : promo courte, supports plats, budget limité

**Polymère** : 3-5 ans, adhésif renforcé, meilleur compromis
→ Quand : durée moyenne, supports variés, qualité encaissée

**Coulé** : 5-7 ans, très conformable, premium
→ Quand : surfaces complexes, longue durée, finition premium

#### FILMS VITRINES
**Transparent** : 88-92% transparence
→ Quand : vitrophanie, vision maintenue

**Dépoli** : 30-50% transparence
→ Quand : intimité + lumière

**Micro-perforé** : One-way vision (voir dedans impossible)
→ Quand : vitrines+affichage, confidentialité

**Solaire** : Bloque 80-90% UV
→ Quand : locaux très vitrés, surchauffe

#### BÂCHES
**Frontlit** : Poids normal, brillance, standard
→ Quand : façades temporaires, chantiers

**Mesh** : 50% aérée, allège vent
→ Quand : zones ventées, échafaudage

**Blockout** : 100% opacité
→ Quand : fermeture urgente, intimité totale

**Textile Enduite** : Premium, souple, rendu tissu
→ Quand : décor intérieur, durée longue

#### SUPPORTS RIGIDES
**PVC Expansé** : Léger, usinage facile, 1-5mm
→ Quand : signalétique intérieure, géométries complexes

**Alvéolaire** : Rigidité/poids excellent, 2-10mm
→ Quand : panneaux volumineux, économie

**Dibond** : Premium rigide, sandwich alu+PE, 3-6mm
→ Quand : enseigne pérenne, finition high-end

**PMMA/Acrylique** : Transparent, rigide, gravable
→ Quand : plaques transparentes premium, vitrines

**Carton Alvéolaire** : Recyclable, très court terme, 3-5mm
→ Quand : exposition, événementiel, 1-3 mois max

#### TEXTILES INTÉRIEUR
**Murs Tendus (SEG)** : Polyester enduit, encastrement profilé
→ Quand : décor intérieur, changement facile, boutiques

**Drapeaux/Textiles** : Polyester 150-200g/m², liseré chaîne
→ Quand : événementiel, signalétique mobile

**Backlit Textile** : Semi-translucide 240-280g/m², LED
→ Quand : enseigne lumineuse, décor premium nuit

## ⚡ UTILISATION RAPIDE

### Quand client pose une question :
1. **Écouter** → Quelle destination ? Durée ?
2. **Poser** → Les 16 questions (adaptation profondeur)
3. **Analyser** → 6 critères décisionnels
4. **Proposer** → Matière + techno + finition + budget + délai
5. **Documenter** → Job ticket + spécifications

### Quand recommandation complexe :
1. CRITÈRE 1 (Durée) → Élimine solutions
2. CRITÈRE 2 (Usage) → Détermine famille
3. CRITÈRE 3 (Support) → Élimine incompatibilités
4. CRITÈRE 4 (Géométrie) → Rigidité vs conformabilité
5. CRITÈRE 5 (Budget) → Affine techno
6. CRITÈRE 6 (Esthétique) → Finition finale

### Quand problème production :
1. **Quelle étape a échoué ?** (discovery/engineering/preflight/prod/livraison)
2. **Cause racine ?** (erreur humaine/spécification/partenaire/techno)
3. **Solution immédiate** (pour ce projet)
4. **Solution durable** (checklist/template mise à jour)
