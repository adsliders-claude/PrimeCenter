# 🟢 SKILL MANAGEMENT — Orchestration Projet

**Objet** : Tout ce qui orchestre le projet (sourcing, timing, communication, équipe).
**Utilisé pour** : Sélection partenaire, gestion projet, communication client, formation équipe.

## 📚 SECTIONS

### 1️⃣ SOURCING & SÉLECTION PARTENAIRE

#### 5 Critères de Sélection (Hiérarchie)

**CRITÈRE 1 : CAPACITÉ TECHNIQUE**
- Techno disponible ? (UV plat/roll, éco-solvent, sublimation ?)
- Supports max ? (dimensions, épaisseurs acceptées)
- Finition possible ? (lamination, découpe, rainage, usinage)
- SLA délai ? (PDF reçu → livraison = combien jours ?)
- Qualité baseline (erreurs acceptables ?)

**CRITÈRE 2 : QUALITÉ**
- Track record ? (références clients satisfaits)
- Certifications ? (ISO 12647, GWG, M1)
- Préflight systématique ? (ou vérifier nous-même)
- Gestion couleur ? (profil ICC, ΔE mesuré)
- Taux retouches/défauts ? (% rejeté acceptable)

**CRITÈRE 3 : PRICING & VOLUME**
- Volume annuel → détermine tarif
- Volume break ? (Qte 1 / 10 / 100 / 500 = quels prix ?)
- Conditions ? (net 30/60 ? Acompte ?)
- Urgence possible ? (rush possible ? Surcoût ?)
- Réassorts ? (stock tampon possible ?)

**CRITÈRE 4 : RÉSILIENCE & PARTENARIAT**
- Délais fiables ? (respecte promesses ?)
- Aléas gérés ? (problème ≠ excuse, solution rapide)
- Seconde source possible ? (risque fournisseur unique ?)
- Communication fluide ? (EDI/API possible ? Contact dédié ?)
- Longévité partenaire ? (stabilité financière ?)

**CRITÈRE 5 : STRATÉGIE LONG TERME**
- Alignement values/process (fit culturel)
- Amélioration continue possible ? (réunion annuelle review)
- Evolution techno accompagnée ? (nouveaux matériaux)
- Scalabilité ? (grandir avec nous possible)

#### Points à Challenger en Sourcing (Le Discours Pro)

```
1. PRIX
   Question : "Pourquoi ce prix ? C'est le meilleur marché possible ?"
   Attente : Justification (coûts matière, opération, marge)
   Action : Négocier volume breaks, comparer 3 fournisseurs

2. DÉLAI
   Question : "Combien de temps du PDF reçu à livraison ?"
   Attente : Timeline réaliste (production + emballage + transport)
   Action : Ajouter buffer (20% délai promise), documenter rush

3. QUALITÉ
   Question : "Tolérance couleur ΔE ? Épreuve incluse ? Retouches ?"
   Attente : Engagement qualité clair (ΔE < 3, Preuve, retouches SLA)
   Action : Audit, visiter atelier, demander certificats

4. EMBALLAGE
   Question : "Protection, traçabilité, écologique ?"
   Attente : Emballage = inverse du coût (destruction/transport)
   Action : Valider protection arrive intact, docum traçabilité

5. FLEXIBILITÉ
   Question : "Modifications de last minute ? Urgence ? Rush possible ?"
   Attente : Réactivité acceptée (rush = surcoût mais pas refus)
   Action : Négocier SLA urgence, accord rush pricing

6. RÉFÉRENCES
   Question : "Clients satisfaits ? Pouvez-vous me presenter ?"
   Attente : Références vérifiables, cas d'usage similaires
   Action : Appeler 2-3 références avant décision finale
```

```
╚════════════════════════════════════════════════════════════════════╝

J0 : DISCOVERY CALL
├─ Durée : 30-60 min
├─ Activité : Questions client (16 questions diagnostiques)
├─ Sortie : Brief synthétisé, risques early identifiés
└─ Délai buffer : 0j (sauf audit site requise, +1-2j)

J0-1 : AUDIT + RECOMMANDATIONS
├─ Durée : 1-2 jours
├─ Activité : Audit site (si nécessaire), recommandation matière/techno
├─ Sortie : Recommandation écrite + options budget
└─ Délai buffer : +0-1j (si audit site compliqué)

J1-3 : SOURCING + DEVIS
├─ Durée : 2-3 jours
├─ Activité : Interroger 2-3 fournisseurs, récupérer devis
├─ Sortie : 3 options (économique/standard/premium) avec délais
└─ Délai buffer : +1j (si fournisseur lent ou besoin affinage)

J3-5 : BAT VISUEL + APPROBATION CLIENT
├─ Durée : 2-3 jours (attente client = le plus long)
├─ Activité : Créer BAT, envoyer client, itérer feedback
├─ Sortie : BAT SIGNÉ client (couleur approuvée)
└─ Délai buffer : +2-3j (clients lents, demandes modif)

J5-7 : FICHIERS FINALISÉS + PRÉFLIGHTS
├─ Durée : 2 jours
├─ Activité : Corriger selon feedback, préflight systématique
├─ Sortie : PDF final validé + rapport préflight
└─ Délai buffer : +0-1j (si modifs importantes)

J7-10 : PRODUCTION (Délai variable selon techno)
├─ Vinyl/Bâche impression : 2-3 jours
├─ Rigide (Dibond, PVC) : 1-2 jours
├─ Découpe/Rainage : +1-2 jours additionnel
├─ Lamination/Finition : +0-1 jour
├─ Sortie : Produit fini + photos QC
└─ Délai buffer : +1-2j (problème machine, retry)

J10-12 : CONTRÔLE QUALITÉ + EMBALLAGE
├─ Durée : 1-2 jours
├─ Activité : QC final, photos, emballage protection
├─ Sortie : Produit packagé, prêt à livrer
└─ Délai buffer : +0-1j (retouche si nécessaire)

J12-15 : LIVRAISON/TRANSPORT
├─ Durée : 1-3 jours (selon distance + transporteur)
├─ Activité : Expédition, suivi logistique
├─ Sortie : Produit livré site client
└─ Délai buffer : +1-2j (délai transport imprévisible)

J15-30 : POSE + PV RÉCEPTION
├─ Durée : Dépend installation (1j à plusieurs semaines)
├─ Activité : Pose (par nous ou client), PV réception
├─ Sortie : PV signé + photos avant/après
└─ Délai buffer : À négocier avec client

═════════════════════════════════════════════════════════════════════
RÉSUMÉ DÉLAI STANDARD
═════════════════════════════════════════════════════════════════════
  - Discovery + Sourcing  : 3-5 jours
  - BAT + Validation      : 2-3 jours (client peut ralentir)
  - Production           : 2-3 jours (selon complexité)
  - QC + Livraison       : 2-4 jours
  ────────────────────────────────
  TOTAL MINIMUM          : 10-15 jours (si tout OK)
  TOTAL RÉALISTE         : 14-21 jours (+ buffer client)
  TOTAL PESSIMISTE       : 25-30 jours (retouches, urgence)

⚠️ RÈGLES DÉLAI
1. Date contractuelle = promettre +50% délai minimum
   → Si client dit "2 semaines", promettre 3 semaines internement
   → Buffer = protection contre imprévus

2. Tight délai = refuser complexité
   → 1 semaine = géometrie simple, couleur non-critique
   → Sinon = refuser ou accepter risque client

3. Partenaire = +30% délai additionnel
   → Coordination sous-traitant = ralentit toujours
   → Sourcing parallèle = gagner 2-3 jours

═════════════════════════════════════════════════════════════════════
```

#### Risques Typiques & Mitigation

| Risque | Cause | Impact | Mitigation |
|--------|-------|--------|-----------|
| **Délai tight** | Client change d'avis tard | Retard livraison | Buffer +3j, refuser complexité, sourcing parallèle |
| **Couleur critique** | Pas d'accord couleur policy | Rejet client | Épreuve incluse systématique, ΔE documenté |
| **Support complexe** | Audit surface incomplet | Adhésion échoue | Visite terrain, échantillon test, primaire prevu |
| **Multi-sites** | Coordination logistique | Livraison fragmentée | Centraliser tracking, checklist par site |
| **Partenaire lent** | Fournisseur saturé | Retard cascade | Seconde source parallèle, suivi SLA strict |
| **Modification BA** | Client demande changement | Retard + surcoût | Bloquer modifications J5+ (délai/coût contract) |
| **Épreuve couleur** | Pas de profil ICC correct | ΔE > 5 inacceptable | Audit machine partenaire, profil standard GWG |

### 3️⃣ COMMUNICATION CLIENT (Les 5 Questions Pro)

**Objectif** : Révéler l'usage réel & anticiper 80% des problèmes.

#### Les 5 Questions Fondamentales

**Question 1 : "Quelle est exactement la destination finale ?"**
- ✓ Pas "une façade" → "Garage rez-de-chaussée, face nord, mur béton"
- ✓ Contexte : intérieur/extérieur, UV, humidité, trafic
- 💡 Révèle : Matière, durée réelle, finition attendue

**Question 2 : "Combien de temps faut-il que ça tienne ?"**
- ✓ Pas "longtemps" → "Minimum 3 ans, idéal 5"
- ✓ Durée fixe ou flexible ?
- 💡 Révèle : Budget matière, techno encre, lamination

**Question 3 : "Sur quoi exactement on colle ou pose ?"**
- ✓ Pas "une surface" → "Béton brut poreux, jamais préparé, possiblement humide"
- ✓ État ? Propre ? Ancien ? Peinture qui lâche ?
- 💡 Révèle : Adhésif, primaire possible, préparation requise

**Question 4 : "Qui va faire la pose ?"**
- ✓ Équipe pro interne ? Client lui-même ? Poseur spécialisé ?
- ✓ Niveau d'exigence = varie énormément
- 💡 Révèle : Complexité acceptable, responsabilité, SLA pose

**Question 5 : "Y a-t-il une date limite non négociable ?"**
- ✓ "Possible" vs "contractuelle" vs "immobile (événement)"
- ✓ Pénalités si on dépasse ?
- 💡 Révèle : Buffer délai requis, urgence réelle, pricing rush

```
JOUR 3️⃣ : LOGIQUE MATIÈRE — 6 CRITÈRES DÉCISIONNELS (3 heures)
──────────────────────────────────────────────────────────
▸ Pourquoi 6 critères ? (ordre = éliminer progressif)

▸ Critère 1 : DURÉE (élimine)
  < 7j → Carton / 1-3m → Monomère / 3-12m → Polymère
  1-3a → Coulé/Dibond / 3-7a+ → Coulé OBLIGATOIRE

▸ Critère 2 : USAGE (détermine)
  Intérieur/Extérieur/Véhicule/Vitrine/Textile
  Chaque ≠ famille matière

▸ Critère 3 : SUPPORT (élimine incompatibilités)
```
